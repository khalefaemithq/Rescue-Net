# Rescue-Net

يحتوي هذا الفرع على نسختين كاملتين من لعبة **Rescue Network** في مجلدين منفصلين:

| المجلد | المحتوى |
| --- | --- |
| [`original-user-source/`](./original-user-source) | المصدر الأصلي كما قدمه صاحب المشروع. |
| [`latest-manus-build/`](./latest-manus-build) | آخر نسخة مطورة، وتشمل مراحل الساحل والبركان والثلوج والأصول الخارجية. |

تحتفظ الفروع المنفصلة أيضًا بالنسختين نفسيهما: `original-user-source` و`latest-manus-build`.
