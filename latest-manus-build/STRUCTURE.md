# البنية الفنية

| الملف | المسؤولية |
|---|---|
| `client/src/game/stages.ts` | تعريف بيانات الجزر: الخلفية، مواقع الأهداف، نفق الإخلاء، نقاط الطرق، والقيود الزمنية. |
| `client/src/game/stageEngine.ts` | محاكاة عامة للإنقاذ، الطاقة، جبهة اللاڤا، إغلاقات الثلج، وتعطل المركبات. |
| `client/src/pages/Home.tsx` | شاشة اختيار المراحل وطبقة SVG موحدة للعب والحالة والنتائج. |
| `client/src/index.css` | تصميم غرفة العمليات، المؤثرات الطبيعية، ومعالجة الهاتف والوصول الحركي. |

> المبدأ: **البيانات تصف الجزيرة، والمحرك يطبق قواعد الخطر، وواجهة واحدة ترسم المراحل كلها.**

تسير المركبات وفق نقاط الطريق المعرّفة لكل هدف بدلاً من رسم خطوط لعب فوق الخريطة. وهذه الاستراتيجية تحافظ على لغة الخريطة المصورة، وتجعل مؤثرات البركان والثلوج طبقات مستقلة يمكن إيقافها أو تخفيفها بصريًا دون التأثير في مسارات المركبات.
