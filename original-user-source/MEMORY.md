# ملاحظات التنفيذ

- مشروع اللعبة React/SVG وليس Babylon؛ الاستمرار في SVG مناسب للنطاق الحالي والحجم الصغير.
- الأصول المولدة لا تُحفظ داخل المشروع، بل تُعرض من روابط `/manus-storage/` الثابتة.
- حلّ خطأ المعاينة السابق بإضافة `dotenv` إلى الاعتماديات وإعادة تشغيل الخادم.
- صور المعاينة يجب أن تستخدم `?demo` أو `?result` عند الحاجة لإظهار اللعب أو النتيجة بشكل حتمي.
- تحقق الأداء الداخلي على 375×812 أعاد خريطة جاهزة مع 3 مركبات و3 أصول أهداف، وبلغ DOMContentLoaded نحو 180ms محليًا. هذا تحقق مخبري وليس وعدًا بزمن شبكة المستخدم.
- طبقة الصوت تستخدم Web Audio وتبدأ من إيماءة المستخدم عند بدء المهمة أو إنشاء مسار؛ اختبار التفاعل headless يتحقق من مسار التفعيل وربط المؤثرات، لكنه لا يثبت مستوى السماع الفعلي لسماعة هاتف أو إعداد كتم الجهاز. يجب الاستماع يدويًا على هاتف فعلي قبل إصدار Steam أو أي ادعاء بمعايرة الصوت النهائية.
