# البنية

تظل قواعد اللعب داخل `client/src/game/engine.ts` كي تبقى مستقلة عن واجهة React. تُعرض الأصول الصغيرة بواسطة طبقة SVG داخل `Home.tsx` وتُحمّل من تخزين المشروع. يجمع `client/src/game/audio.ts` نغمات Web Audio المولّدة في المتصفح؛ لذلك لا تضيف ملفات صوتية للحزمة. تتولى CSS حركات المطر والبرق ونبض نقاط الإنقاذ.

## تدفق النهاية

`tickGame` يخفض الوقت ثم ينقل الجولة إلى حالة النهاية. يسجل المحرك عدد المنقذين والخسائر، وتعرض الواجهة طبقة عاصفة نهائية وبطاقة نتيجة تصف القرار الحاسم.
