# حزمة المصدر الكاملة — شبكة الإنقاذ

هذا الأرشيف يطابق الإصدار المنشور `043b9592` من لعبة **شبكة الإنقاذ**.

## التشغيل المحلي

ثبّت الاعتماديات ثم شغّل خادم التطوير:

```bash
pnpm install
pnpm dev
```

تتضمن الحزمة الواجهة، محرك اللعبة، الاختبارات، نصوص فحص الهاتف، توثيق شبكة الطرق، وملف قفل الحزم. أصول اللعبة الكبيرة مخزنة في مسارات `/manus-storage/` المشار إليها داخل المصدر، لذلك لا تُنسخ داخل الأرشيف.

## فحوص الجودة

```bash
pnpm test
pnpm check
pnpm test:interaction
pnpm test:performance
pnpm build
```

في هذا الإصدار، لا توجد طبقة طريق مرسومة فوق المدينة؛ تتحرك المركبات فوق الخلفية الأصلية. الطرق الأساسية تستخدم المعدل `2.3`، ويقتصر المعدل `1.15` على تحويلي الفيضان والانهيار.
